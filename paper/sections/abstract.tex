Open-source model hubs make it trivial to load weights whose declared license cannot be
trusted: recent audits find that 95.8\% of models lack the required license text and that
35.5\% of model-to-application transitions silently strip restrictive (copyleft)
clauses~\cite{jewitt2026permissivewashing,jewitt2025licensedrift}. For a permissively-licensed
project, loading a single AGPL model virally relicenses the whole
deployment~\cite{ultralytics2023yolo,agpllicense}. We present \textbf{VisionServe}, a
single-binary Go inference server that is, to our knowledge, the first inference runtime to
enforce a permissive-license allowlist \emph{at model-load time}: it binds each model's
declared license to specific weight bytes (sha256) and an audited \texttt{source\_url},
entirely offline, and refuses to load anything outside the policy. This is load-time
license-\emph{policy} enforcement, hardened by content-hashing and a verified-source
allowlist---a gap that build-time SCA scanners, deploy-time Kubernetes admission controllers,
and model signing structurally do not cover. We further characterize the CV serving-overhead
crossover: on identical ONNX, the single Go binary scales to roughly $8\times$ a GIL-bound
FastAPI+ONNX~Runtime baseline's peak goodput (695 vs.\ 85~rps for MobileNetV3-Small at
concurrency~64), while being slower per request at low load ($\sim$78\,ms vs.\ $\sim$15\,ms at
concurrency~1). A latency decomposition shows the per-request cost is pure-Go JPEG decode and
resize, not the GPU (ORT~Run $<$1\,ms; JPEG decode $\sim$19\,ms); when clients submit a
pre-decoded tensor (skipping server-side image decode), VisionServe matches a default
Triton's inference-serving ceiling ($\sim$563 vs.\ $\sim$549~rps) at $\sim$3.4\,ms latency,
showing that decode---not the runtime---was its only deficit. Export and serving preserve
accuracy to within 0.5\% Top-1 of commonly-cited references. VisionServe also serves 16
registered models across 6 CV task types (12 benchmarked). It is released under the
Apache-2.0 license and is available at \url{https://github.com/}{[repository]}.
